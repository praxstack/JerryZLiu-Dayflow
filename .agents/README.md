# Agent skills (super-pro stack)

Skills for Dayflow Cloud Agents install **globally** to `~/.agents/skills`, not into this directory.

| File | Purpose |
|------|---------|
| `super-pro-packs.json` | Manifest of all recommended packs and install modes |
| `~/.agents/.skill-lock.json` | Global lock file (auto-generated by skills CLI after install) |

## Sync on a fresh VM

```bash
bash scripts/install-super-pro-skills.sh
bash scripts/verify-super-pro-skills.sh
```

See [docs/super-pro-stack.md](../docs/super-pro-stack.md) for architecture, overlap warnings, and desktop-only steps.
